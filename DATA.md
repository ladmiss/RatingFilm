# Данные и эксперименты

Карточка «ФильмРейтинг» из файла «СПбГУ_6_проектов_11_2026.md», раздел 4, задаёт размеры, обязательные методы и правила оценки. Общая методичка задаёт требования к воспроизводимости и анализу устойчивости.

## Схема

| Таблица | Одна строка | Поля |
| --- | --- | --- |
| `movies` | Вымышленный фильм, доступный с первого дня | `movie_id` — целый уникальный ключ, `title` — вымышленное название, `genre` — один из пяти жанров |
| `users` | Вымышленный пользователь | `user_id` — целый уникальный ключ |
| `ratings` | Событие оценки | `rating_id` — целый уникальный ключ, `user_id` и `movie_id` — внешние ключи, `timestamp` — условная дата, `rating` — баллы от 1 до 5 с шагом 0,5 |
| `private/movie_parameters` | Скрытые параметры фильма | `movie_id`, `base_rating` — базовый балл, `popularity_weight` — вес выбора |
| `private/user_parameters` | Скрытый параметр пользователя | `user_id`, `rating_bias` — смещение в баллах |

Справочник `movie_titles.tsv` содержит по 40 вымышленных названий для каждого из пяти жанров. Название назначается внутри жанра. В формулах популярности, оценки и прогноза текст названия не участвует.

## Модель генерации

Базовый балл независимо от веса популярности выбирается из нормального распределения со средним 3,2 и стандартным отклонением 0,65. Веса логнормальные со средним 0 и стандартным отклонением 1,85 на логарифмической шкале. Пары пользователей и фильмов выбираются без возвращения. На каждом шаге вероятность выбрать одну из оставшихся пар пропорциональна весу её фильма. Временные метки выбираются равномерно по дням.

К базовому баллу добавляются смещение пользователя (нормальное распределение со средним 0 и стандартным отклонением 0,4) и независимый нормальный шум события (среднее 0, стандартное отклонение 1,05). Результат округляется до ближайших 0,5 и ограничивается диапазоном 1–5. Скрытые параметры постоянны во времени. Жанры распределены поровну и случайно. Код прогнозов получает только наблюдаемые оценки и время.

Шкалы распределений — допущения учебного сценария. Основной профиль даёт 20 000 оценок от 1 000 пользователей для 200 фильмов за 360 дней. Запасной профиль даёт 3 000 оценок от 100 пользователей для 60 фильмов за 180 дней. Оба профиля используют правила из `config.json` с отдельными seed.

## Эксперименты

- Сортировка идёт по времени, при совпадении меток на границе все такие события входят в более раннюю часть. Фактические границы и размеры записываются в `results/split.csv`.
- На валидации сравниваются α = 5, 20 и 50. Если RMSE отличается от минимума не более чем на 0,001, выбирается наибольший допустимый α. После выбора три метода прогнозируют один и тот же тест по фиксированной истории из обучения и валидации.
- Обычные топы по среднему включают фильмы с наблюдаемым средним. В топы по числу голосов и по сглаженному среднему входят все фильмы. Для фильма без голосов сглаженный балл равен общему среднему. При равном балле или числе голосов сортировка идёт по возрастанию `movie_id`.
- Для каждого из трёх предтестовых окон последние 20% предшествующих дат отведены под выбор α. После выбора средние пересчитываются по всей истории до окна. Даты внутренней валидации и выбранный α сохранены в period_stability.csv. В дополнительном эксперименте берутся три пары независимых наборов оценок того же каталога и считается пересечение обычных и сглаженных топ-10. Перед этими генерациями применяется α, выбранный на основной валидации.

## Проверки

Пробный профиль проверяет размер таблиц, уникальность ключей и пар, внешние ключи, сохранение числа строк при объединении, диапазон и шаг оценок, наличие обеих групп популярности и совпадение данных при повторной генерации с тем же seed. Временные границы, прогноз без истории, пример сглаживания, правило выбора α и одинаковый состав событий для метрик также проверяются автоматически. Проверки выполняются во всех трёх профилях. Подробный список находится в `results/checks.csv` каждого прогона.

## Откуда взялись методы

IMDb публикует формулу для своего Top 250. В ней вес среднего по фильму растёт с числом голосов. В учебном эксперименте ту же идею проверяем на шкале 1–5. Параметр α подбираем на валидации. [IMDb, Ratings FAQ](https://help.imdb.com/article/imdb/track-movies-tv/faq-for-imdb-votes/G67Y87TFYYP6TWAV)

Хайндман и Атанасопулос описывают проверку прогнозов с последовательно сдвигающейся временной границей. У нас три последовательных окна и отдельный финальный тест. [Forecasting: Principles and Practice, §5.10](https://otexts.com/fpp3/tscv.html)

Кэмерон и Миллер разбирают повторный выбор целых групп с возвращением. Для сравнения прогнозов мы выбираем фильмы и переносим все их тестовые оценки вместе. Интервал условен на зафиксированные прогнозы и сценарий генерации. [Cameron и Miller, A Practitioner’s Guide to Cluster-Robust Inference](https://facultysites.dss.ucdavis.edu/research/Cameron_Miller_JHR_2015_February.pdf)
