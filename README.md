# РейтингФильм

У фильма одна пятёрка, у другого — среднее 4,5 по сотне голосов. Кто окажется выше в топе и какой балл точнее предскажет следующую оценку? В проекте это два отдельных эксперимента. Топы строятся по прошлым голосам, точность проверяется на следующих по времени.

[Печатный отчёт](film-rating.pdf) · [Интерактивный разбор](runs/main/report.html) · [Полный отчёт с таблицами](runs/main/report.md) · [Памятка для защиты](DEFENSE.md)

## Запуск на своём компьютере

Распакуйте архив и откройте терминал в папке с `run.py`. Проверенная версия — Python 3.11. Команды выполняются на CPU.

```sh
python -m pip install -r requirements.txt
python run.py --profile quick
python run.py --profile main
```

`quick` проверяет небольшой набор. `main` создаёт 200 фильмов, 1 000 зрителей и 20 000 оценок, затем строит таблицы, рисунки и оба отчёта в `runs/main/`. Для сверки с готовыми файлами можно направить новый запуск в другую папку: `python run.py --profile main --output runs/repeat`.

Запасной профиль из задания запускается командой `python run.py --profile fallback`. В нём 60 фильмов, 100 зрителей и 3 000 оценок. Если основной вариант не укладывается в доступное время или память, переход согласуют с преподавателем до открытия теста. В архиве показаны результаты обоих вариантов. [Измерения времени и памяти](EXPERIMENTS.md)

Проверить расчёты по сохранённым CSV можно отдельно: `python verify_results.py --profile main`. Этот скрипт пересчитывает прогнозы через стандартную библиотеку Python.

## Как устроена работа

| Что искать | Где лежит |
| --- | --- |
| Параметры генерации, seed, кандидаты α | [config.json](config.json) |
| Как получается одна оценка, схема таблиц и допущения | [DATA.md](DATA.md), [generate.py](generate.py) |
| Три прогноза, четыре топа, деление по времени | [analysis.py](analysis.py) |
| Интервалы по фильмам и разбор промахов | [research.py](research.py) |
| Весь эксперимент от генератора до отчёта | [run.py](run.py) |
| Поштучные прогнозы на тесте | [test_predictions.csv](runs/main/results/test_predictions.csv) |
| Ошибки по группам и результаты проверок | [test_metrics.csv](runs/main/results/test_metrics.csv), [checks.csv](runs/main/results/checks.csv) |
| Фамилии и фактический вклад | [TEAM.md](TEAM.md) |

Раздел о вкладе берётся из `TEAM.md` при запуске. Печатный отчёт можно пересобрать отдельно из сохранённых CSV и PNG: `python -m pip install reportlab==4.4.9`, затем `python make_handout.py`. Основной эксперимент использует только зависимости из `requirements.txt`.
